演示账号池网关接入
开始使用

One endpoint替你管好每个账号

把 CodeBuddy 账号变成 OpenAI 接口。多账号池、熔断冷却、会话粘性都由网关处理，客户端只改一个 base URL。

获取接入地址 看账号池怎么工作

One command 一条命令拉起网关

agent 在本地运行，账号凭据不出机器。启动时自动签到、回血、装填账号池。

zsh — workbuddy2api

    

  







  

    

      
账号不是用坏的
是被同时打坏的

      
每个账号有独立的限流窗口。网关按冷却时间而不是轮询来调度，哪个能回池、什么时候回，都在一张表里。

    

    

      
熔断冷却
命中 429 后按 Retry-After 下线账号，到点自动回池，不猜测、不提前。

      
会话粘性
同一个 conversation_id 固定落到同一账号，上下文连续，不被切到别的号。

      
积分可见
每次请求回写积分，/v1/pool 直接返回，不用再登后台翻。

    


    

      
账号状态积分冷却

      
a1可用1,240

      
a3可用980

c2可用2,060

      
c3封禁0

    

  







  

    

      

        
改一行 base URL 其余不动

        
OpenAI 的 /v1/chat/completions 原样透传。SDK、Agent 框架、CLI 都不用改代码，只改环境变量。

        

          
Base URLhttp://127.0.0.1:8787/v1

          
模型GLM-5 · Hermes

          
协议OpenAI 兼容 · SSE 流式

          
账号池9 个 · 6 可用

        

      

      

        
zsh

        
$ export OPENAI_BASE_URL=http://127.0.0.1:8787/v1
$ curl $OPENAI_BASE_URL/chat/completions \
    -d '{"model":"glm-5","messages":[{"role":"user","content":"hi"}]}'

  "id": "chatcmpl-7f2a",
